# Stardew Valley Fishing Bot (Mini‑Game Only)  
Бот для автоматизации мини-игры рыбалки в Stardew Valley  
Зависимости: opencv-python, mss, pywin32, numpy, pynput и template.png в images  
```bash
pip install -r requirement.txt
```
## Запуск
```bash
python script.py
```
Бот работает только при появлении мини-игры, удерживая зелёную зону на рыбе.

## Необходимо поставить оконный режим или изменить template.png
